# Telas do Agendei

Capturas do sistema rodando com os dados de demonstração criados pelo
`instalar.php` (estabelecimento **Agendei Studio**). As imagens ficam em
[docs/prints/](docs/prints/), em resolução de 1366 px de largura (computador)
e 390 px (celular).
